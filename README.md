# PPK — React Native (Expo) Practicum

A React Native learning project built for the **PPK (mobile development) practicum**, using Expo SDK 58, Expo Router, and TypeScript.

## What's inside

- Expo Router file-based navigation with typed routes
- Reusable UI components and theming (light/dark)
- Lab exercises and sprint documentation
- Automated tests

## Documentation

- [PPK 101](PPK%20101.md) — first-time React Native setup
- [Mobile Environment Configuration](docs/Mobile%20Environment%20Configuration.md)
- [Sprint 1 — Interfaces and Practicum Flow](docs/sprint-1/README.md)

## Tech stack

`React Native` · `Expo SDK 58` · `Expo Router` · `TypeScript` · `EAS`

## Getting started

```bash
npm install
npx expo start
```

Run on Android/iOS via Expo Go or a development build. The `reset-project` script is destructive and intended for first-time setup only.

## Structure

```
app/            routes (Expo Router)
src/            components, hooks, utilities
assets/         icons, splash, images
tests/          unit tests
docs/           practicum documentation
```
